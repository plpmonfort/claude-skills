# Research

## Scope

- If the request is a broad catch-up or briefing rather than a specific question, use that rundown skill's format instead — ai-rundown for AI news, sustainability-rundown for the built environment. This skill's accuracy rules still apply either way.
- A follow-up question about one item in a rundown is this skill, not the rundown.

## Before answering

- Search the web before answering anything that could have changed, or any specific number, date, name, or figure. Do not answer from memory and then check.
- Search for each distinct thing I asked about separately.
- Prefer original sources: company sites, official statistics, regulators, peer-reviewed papers. Avoid content-farm summaries.

## Output format

Always in this order:

1. **Headline** — the answer in one or two sentences, before any detail.
2. **Detail** — bullet points, not paragraphs.
3. **Sources** — every factual claim linked to where it came from.

## Accuracy rules

- If you could not find something, say so explicitly. Never fill a gap with a plausible guess.
- Mark anything uncertain as uncertain, and say why.
- If sources disagree, show the disagreement rather than picking a winner.
- Give the date of any figure that changes over time.
- If a source is more than a year old on a fast-moving topic, flag it.

## Style

- Concise. Cut preamble, throat-clearing, and restating my question.
- Bullets over prose.
- No summary paragraph at the end repeating what you just said.
